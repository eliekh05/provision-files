# Provision Files

A community-maintained archive of macOS provisioning profiles extracted from applications that include them.

Instead of scouring the web for a specific provisioning profile, you can easily browse this repository, download the exact profile you need, and install it directly on your Mac.

## What is Included?

This repository contains provisioning profiles extracted from macOS application bundles. 

> **Note:** Not every macOS application contains a provisioning profile. This repository only hosts profiles that are actually available from their corresponding applications.

## Directory Structure

All extracted `.provisionprofile` files are organized and stored within the dedicated profiles folder in this repository. 

## Installation

1. **Locate** the provisioning profile for the application you need within the profiles folder of this repository.
2. **Download** the specific `.provisionprofile` file.
3. **Open** the downloaded file on your Mac.
4. **Install** by following the standard macOS on-screen prompts.

*Note: The availability and behavior of provisioning profiles can vary between different application versions and distribution methods.*
